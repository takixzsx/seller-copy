# 게시물 5 대본 (릴스 — 팩 안내 + 프로필 유도)

형식: 릴스 (화면 녹화). 다른 게시물과 달리 이건 사용자님이 직접 촬영해야 합니다.

## 녹화 내용

1. (0~2초) 자막: "프롬프트 8개, 그냥 다 무료로 정리했습니다"
   화면: /pack 페이지 여는 장면
2. (2~6초) /pack 페이지를 천천히 스크롤 (프롬프트 카드들이 지나가는 것을 보여줌)
3. (6~9초) 아무 프롬프트나 하나 클릭해서 "복사하기" 버튼 누르는 장면 (복사 완료 토스트 나오는 순간 강조)
4. (9~11초) 자막: "가입도 이메일도 필요 없어요"
5. **(11~13초) — 여기가 지난 릴스에서 빠졌던 부분입니다**
   자막: "↑ 프로필에서 바로 확인하세요" + 화면 위쪽(프로필 방향)을 가리키는 화살표 애니메이션
   (캡컷에서 화살표 스티커 검색하면 있습니다. 위쪽을 가리키게 배치)

## 캡션

```
셀러용 AI 프롬프트 8개를 전부 무료로 정리했습니다.

상세페이지 · 블로그 체험 리뷰 · 인스타 캡션 · 릴스 대본
해시태그 · 광고 카피 · 부정 리뷰 대응까지.

가입도 이메일도 필요 없습니다.
그냥 복사해서 쓰세요.

프로필 링크 → 확인

#스마트스토어 #쿠팡셀러 #이커머스 #상세페이지 #온라인셀러
```

## 왜 화살표를 넣었나

지난 릴스 인사이트에서 조회 1,300 중 프로필 방문이 6건뿐이었습니다.
영상 안에 "프로필로 가라"는 신호가 전혀 없었던 게 원인으로 보여서,
이번엔 명시적으로 화살표 + 자막을 마지막에 넣었습니다.
