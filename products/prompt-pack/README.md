# 이커머스 셀러용 AI 프롬프트 팩 (초안 v0.1)

판매 채널: 크티(CTEE) / Gumroad / Shopify
가격안: 9,900원
상태: **초안 — 판매 전 검수 필요** (아래 "판매 전 체크리스트" 참고)

---

## 이 팩의 포지셔닝

시중 프롬프트 모음의 문제는 "복사해서 붙여넣으면 그럴듯한 글이 나오는데, 내 상품 얘기는 아닌 글"이 나온다는 겁니다.
이 팩은 **빈칸을 채우면 내 상품 정보가 반드시 반영되는 구조**로 만들었습니다.

각 프롬프트는 세 부분으로 되어 있습니다.

- `[역할]` — AI에게 어떤 전문가로 답하게 할지
- `[입력]` — 셀러가 채워야 할 빈칸
- `[제약]` — 지어내면 안 되는 것, 지켜야 할 형식

**`[제약]`이 이 팩의 핵심입니다.** 대부분의 프롬프트 모음이 이걸 빼먹어서, AI가 "만족도 98%", "업계 1위" 같은 검증 불가능한 수치를 지어냅니다. 그대로 상세페이지에 쓰면 허위광고가 됩니다.

---

## 공통 규칙 (모든 프롬프트 앞에 붙이세요)

```
아래 규칙을 반드시 지켜서 답하세요.

1. 내가 입력한 수치, 소재명, 인증명, 규격은 한 글자도 바꾸지 마세요.
2. 내가 주지 않은 수치를 지어내지 마세요. 만족도 98%, 재구매율 85%,
   판매 1위, 임상 테스트 완료, 수상 이력 같은 표현을 만들어내지 마세요.
3. 후기, 평점, 판매량을 사실처럼 쓰지 마세요.
4. "최고", "1위", "유일한" 같은 최상급 표현은 내가 근거를 주지 않았으면 쓰지 마세요.
5. 설득력은 지어낸 숫자가 아니라, 내가 준 특징이 타겟 고객의 어떤 불편을
   해결하는지 구체적으로 연결해서 만드세요.
```

> 이 규칙은 실제 셀러카피 서비스에서 검증한 것입니다. 규칙 없이 생성했을 때
> 입력한 "304 스테인리스"가 "307 스테인리스"로 바뀌어 출력된 사례가 있었고,
> 이 규칙 적용 후 4개 톤 6회 재생성에서 왜곡이 사라졌습니다.

## 사용 팁

1. **한 번에 완성하려 하지 마세요.** 결과를 받은 뒤 "3단락이 약해요, 더 구체적으로"처럼 이어서 요청하면 품질이 확 올라갑니다.
2. **`[입력]`을 성의 있게 채울수록 결과가 좋아집니다.** "좋은 텀블러"보다 "12시간 보온, 304 스테인리스"가 훨씬 나은 결과를 냅니다.
3. **출력된 수치는 반드시 대조하세요.** `[제약]`을 넣어도 100%는 아닙니다. 특히 소재명·규격·인증 번호는 눈으로 확인하세요.
